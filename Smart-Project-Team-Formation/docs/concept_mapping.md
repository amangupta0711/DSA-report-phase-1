# Concept Mapping (Unit 3 and Unit 4)

| Topic | Used? | Reason |
|---|---|---|
| 0/1 Knapsack | Yes | Pick tasks inside a fixed number of hours |
| LCS | Yes | Common interests of two students, order kept |
| Resource allocation | Yes | Share limited students among projects |
| Matrix chain multiplication | No | No matrices in the platform |
| Subset sum | Yes | Find task sets of exact hours |
| Graph colouring | Yes | Meeting slots for teams that share students |
| N-Queens | No | No placement-on-board problem |
| Hamiltonian cycle | No | No need to visit every node once |
| Branch and bound | No | Backtracking with pruning was enough for small data |

DP is used where the same smaller problems repeat (knapsack, LCS, resource allocation).
Backtracking is used where only a rule is checked at each step and we go back on failure
(subset sum, graph colouring).
